# CONCRETE ECHO (콘크리트 에코) — 한국어판

바디캠(신체 착용 카메라) 시점으로 즐기는 브라우저 슈팅 게임입니다. 2층짜리 폐건물에 숨어든 무장 적 11명을 소탕하는 것이 목표입니다. 가슴에 단 카메라로 찍은 실제 녹화 영상처럼 보이도록 어안 렌즈 왜곡, 강한 명암 대비, 센서 노이즈, 압축 영상 특유의 색 번짐, 손떨림까지 그대로 재현했습니다.

- 원작: [Rikinshah787/Game-Fable-5.2](https://github.com/Rikinshah787/Game-Fable-5.2) (원본 리드미: [README.en.md](README.en.md))
- 바로 플레이: **<https://sigco3111.github.io/concrete-echo-ko/>**

## 특징

- **바디캠 룩.** 배럴 디스토션, 카메라 내 샤프닝, 4:2:0 색 번짐, 뭉개진 암부와 날아간 하이라이트, 자동 노출, 모션 블러, 녹화 오버레이까지 실제 바디캠 영상의 질감을 구현했습니다.
- **실제 물리.** 상자, 드럼통, 의자 등 포토스캔 소품 65종이 Rapier 강체로 동작합니다. 총알은 소품을 밀어내고, 나무·판지 같은 얕은 엄폐물은 관통하며, 콘크리트와 강철에서는 멈춥니다. 적은 래그돌로 쓰러진 뒤에도 사격에 반응합니다.
- **세밀한 재장전 연출.** 탄창이 풀려 총구에서 미끄러져 나오고, 빈 탄창은 바닥에 떨어져 남습니다. 덜 쓴 탄창은 파우치로 돌아가고, 장갑 낀 손이 새 탄창을 두드려 끼운 뒤 노리쇠를 당깁니다.
- **4종의 무기.** 소총(AKR), 권총(P9), 한 발씩 장전하는 펌프 산탄총(M12 PUMP), 그리고 충격탄으로 시신과 가구를 날려 버리는 발사기(THUMPER).
- **에코 펄스.** 건물 전체에 탐지 파를 쏴 몇 초간 벽 너머의 적 위치를 보여 주지만, 가까이 있는 적에게는 내 위치를 들킵니다.

## 실행 방법

### 온라인 (권장)

<https://sigco3111.github.io/concrete-echo-ko/> 에 접속한 뒤 **투입** 버튼을 누르면 바로 시작됩니다.

### 로컬 실행

Node.js만 있으면 됩니다. 설치할 의존성이 없습니다.

```bash
npm start
```

<http://localhost:5173> 을 열고 **투입**을 누르세요. `PORT=8080 npm start`로 포트를 바꿀 수 있습니다. WebGL 2와 마우스가 있는 데스크톱 브라우저(Chromium 계열에서 테스트됨)에서 플레이하세요.

## 조작법

| 입력 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 | 무기 조준 (바디캠처럼 카메라가 무기를 따라옴) |

| Esc | 일시정지 |
| Enter | 런 종료 후 재투입 |

## 게임 규칙

- 조준점이 없고 HUD도 거의 없습니다.
- 적은 원뿔형 시야로 보고, 총성을 듣고 찾아옵니다.
- 머리 한 발, 몸통 두 발이면 적이 쓰러집니다.
- 5초 동안 맞지 않으면 체력이 회복됩니다.
- 총알은 상자·종이상자·의자를 관통하며 관통할 때마다 피해가 줄고, 벽·드럼통·콘크리트는 관통하지 못합니다.

## 한글화 방식

- `ko.js`가 화면에 표시되는 영어 문구를 실행 시 한국어로 바꿉니다. 원본 게임 코드는 그대로 두고, MutationObserver로 DOM 변경을 감지해 문구가 나타날 때마다 번역표를 적용하는 오버레이 방식입니다.
- `index.html`의 `lang="ko"` 지정과 한글 폰트 폴백(Apple SD Gothic Neo, Malgun Gothic, Noto Sans KR)을 추가했습니다.
- 무기 이름(AKR, P9, M12 PUMP, THUMPER)과 카메라 장비명(KESTREL BWC-2) 같은 고유 명사, 벽 그래피티·간판처럼 텍스처에 구워진 영어는 원작 그대로 둡니다.

## 기술 스택

- **렌더링:** [three.js](https://threejs.org) r160 (MIT, `vendor/`에 포함)
- **물리:** [Rapier](https://rapier.rs) 0.14 (Apache 2.0, `vendor/`에 포함)
- **코드:** 순수 ES 모듈 JavaScript, 빌드 단계 없음. 로컬 서버는 의존성 없는 Node 정적 파일 서버(`server.js`)
- **에셋:** 텍스처·소품 모델은 [Poly Haven](https://polyhaven.com)의 CC0 포토스캔, 병사 모델은 three.js 예제의 `Soldier.glb`(Mixamo 캐릭터)
- **오디오:** Web Audio API로 합성한 총성·타격음·룸 톤
- **포스트 프로세싱:** `src/post.js`가 왜곡·노이즈·색 번짐·자동 노출 등 바디캠 룩 전체를 셰이더로 처리

## 테스트 훅

게임을 플레이하지 않고 확인할 수 있는 URL 플래그: `?auto`는 바로 시작, `?noai`는 적이 나를 알아채지 못하게 함, `?q=low`는 성능 모드로 시작, `?pos=x,y,z,yaw,pitch`는 시작 위치 이동. 실행 중인 게임은 콘솔에서 `window.__game`으로 접근할 수 있습니다.
